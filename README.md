# Octavia Tech Solutions - Web Application

Enterprise Software, AI & Cloud Engineering web platform built with React, Vite, Tailwind CSS, and TanStack Router.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or bun

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

The application will be available at `http://localhost:8080/`.

### Build & Deployment

```bash
npm run build
```
